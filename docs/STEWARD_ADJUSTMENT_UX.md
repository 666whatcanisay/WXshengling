# D042 · 森林管家调整流程整理

日期：2026-11-06。用户在D041核心接口收尾后要求继续推进；本轮限定本地前端流程整理。保留现有森林风格和云接口，无依赖升级、云部署、真实业务写入或模型请求。

## 现在怎样操作

入口：AI → 森林管家 → 复盘调整 → 下一轮怎么安排。

- 调整区直接显示当前目标，旁边可切换；从这里切换后仍留在复盘调整，原页面顶部选择器继续保持原有“今日安排”行为。
- 上方显示“草案 → 检查 → 确认 → 回执”操作指引及当前下一步。它表示用户操作顺序，真实Agent分工仍由运行步骤记录展示。
- 一个主动作随状态切换：生成、保存改稿、规则检查、确认应用、查询回执或继续原确认。任务对照下方使用同一动作，避免长页面来回找按钮。
- 应用仍要明确确认弹窗。请求异常先查询回执，成功查询但暂无回执后才给“继续提交原确认”，保持原版本/摘要；不自动重试或重新生成。
- 已应用显示回执；确认中、取消及过期版本的名称说明为暂停编辑/只读。取消、主动继续AI审核及本机副本放在“更多操作”，没有删除功能。
- 原生滚动定位跳到对照或展开的要求表单；不支持或失败时提示用户向下查看。

技术上用独立的纯展示函数`adjustmentPresentation.js`计算下一步，仍调用已有工作区的校验、确认、版本、缓存和云端事务接口；不另造一套Agent执行状态。

## 一并修复的恢复边界

1. 生成时离开页面后，本机输入可能标为已改，云端草案却已完成。重进时将输入与确切云稿要求核对：一致则恢复可确认；不一致则保留为待保存改稿，不让按钮永久禁用。
2. 新一轮运行不沿用上一轮的成功回执。
3. 云稿读取暂失败时，仍可凭已持久化的原确认查询/提交；成功回执独立接收，不拼装缺字段的运行对象。
