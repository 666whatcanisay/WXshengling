## 开发检查入口

在Node24环境运行：

```powershell
npm run verify
npm run verify:ui -- --wcc "E:/微信web开发者工具/code/package.nw/node_modules/wcc-exec/wcc.exe" --wcsc "E:/微信web开发者工具/code/package.nw/node_modules/wcc-exec/wcsc.exe"
```

编译器路径示例对应当前电脑；其他机器可通过`--wcc`/`--wcsc`、环境变量`WECHAT_WCC`/`WECHAT_WCSC`指定，或设置安装目录`WECHAT_DEVTOOLS_DIR`，最后才从PATH寻找。显式指定路径无效会报错，不静默改用其他版本，也不安装工具。

`verify:ui`核对全部注册页面的JS/WXML、存在的JSON及tabBar注册关系；JSON/WXSS本身可选，不把项目惯例误当微信硬要求。编译范围为AI页、森林管家、全局及所引用本地组件、自定义tabBar、模板include/import/WXS依赖和WXSS导入；本次共19个注册页面、3份模板、4份样式。外部插件仅列明，不据此声称插件已编译。路径越界、文件缺失、错误JSON、编译失败/超时/空产物均失败退出。编译产物只进唯一系统临时目录，完成后清理该目录，不生成云包或修改源码。

全套业务/工具检查共2037项通过；构建产物、共享上下文一致性检查通过，真实wcc/wcsc编译通过。新增日期66项、导航/生命周期11项、工具28项、规划恢复5项；工具检查验证的是文件与子进程处理，不能代替微信运行时。
