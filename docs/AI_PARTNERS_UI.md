## AI审核师

- 无草案：明确说明来源，支持到原规划师准备或刷新；不造示例计划、不重新生成。
- 有草案：优先读取当前账号待确认发布原稿，否则读取当前账号页面内的规划师编辑稿。展示标题、周期、开始日期、任务数、可展开的任务清单和对话整理字段。
- 字段来自现有规划对话整理，可能含模型概括，页面提示用户核对，不冒称全部为已确认要求。
- 前端快照内容改变时递增本页编号；再次读取相同稿不递增。快照独立于工作副本，避免用户修改任务时悄悄改变已经展示的内容。此编号不是服务器草案版本或审核回执。
- 返回查看/修改保留原草案、对话；待确认原稿继续锁定。原计划弹窗新增“到审核师查看这份草案”入口，发布中不展示。
- 审核依据、问题与建议的版面已完成。AI审核按钮禁用并标注待接入，没有评分/通过结论，不改变原发布校验或强制新增AI审核关卡。

## AI教练

- 主动选择目标和单个日期，读取现有goals/tasks，显示该目标该日任务及已完成/待完成数量、完成比例。零任务不计算比例；日期不能选未来。不是周报/累计/连续任务完成天数。
- 目标/任务失败明确提示与重试，快速切换时忽略旧响应，隐藏/离开后不接收晚到结果。原教练随机建议、0目标回退3、失败仍假报“分析完成”等路径已从当前前端移除。
- 主动反馈提供影响因素与500字备注，按账号/目标/日期保存在本机，切换前保存，保存失败阻止上下文切换。读取失败先重试，不覆盖已有本机反馈。不是云端反馈采集或模型长期记忆。
- AI复盘/未来调整仍待后端，按钮禁用；不读取心情示例或推断实际耗时，不自动改任务或奖励。
