## 森林礼包回执与背包刷新（本地）

- 新手礼包、儿童节礼包共用森林页的账号会话校验和提交锁。同一微信重新注册后，旧领取结果不会隐藏新账号的礼包，也不会修改新账号的库存。提交结果不明时可回读当前账号的领取状态。

## 泉水灌注与背包道具断线恢复（本地）

## 手动添加任务的断线恢复（本地）

- 「目标 → 目标详情 → 添加新任务」在提交前把任务名称、日期、经验和请求编号保存在当前账号及目标下。网络中断或退出后，重新打开目标可选「继续确认上次添加」，界面展示原任务日期并提交同一编号。明确拒绝时解锁表单并保留原文字。
- 新客户端使用 `createTaskOnce`。云函数按微信身份、账号 ID 和请求编号定位任务，在同一事务中更新目标并添加任务。并发、重试或目标随后关闭时可拿回已受理的原任务，同编号换内容会被拒绝。旧 `createTask` 入口继续兼容已有调用。
- 旧云函数缺少新入口时，新客户端保留原稿并提示更新。线上需要先更新 `app-node24`，再配套更新小程序。目标专项 81 项、云路由专项 50 项、并发事务回归、Node24 全套离线回归及目标详情微信模板和样式编译通过。真机验收待完成。

## 目标列表与详情回执隔离（本地）

- 「目标」列表只接收当前登录会话的最新读取结果。切换账号会清空旧列表、展开状态和页面表单，旧创建回执无法关闭新账号的表单。已提交待确认的原请求可按账号恢复。
- 「目标 → 今日」同一任务防连点。收到明确打卡回执后更新当前任务，进行中的旧刷新重新读取；跨北京时间日期时刷新今日任务。任务经验和宠物成长仍由原云函数结算。
- 「目标 → 目标详情」的读写回执绑定打开页面时的会话。旧打卡结果、添加任务回执、完成或放弃目标的确认均无法写入新账号界面。详情检测到账号变化时清空旧目标内容，提示返回重新打开。

## 规划师创建生成任务的回执（本地）

- 「AI → 规划师 → 生成计划」先保留本次创建请求编号。同一页面、同一对话与草案版本及生成内容下，首次响应丢失后再次点击会核对原请求。已发起的请求继续关联原服务商，用户修改规划内容后开启新请求。
- 云函数按账号和请求编号事务创建。相同请求返回原任务 ID 和当前状态，不同内容复用编号会拒绝。创建结果不明时保留当前对话，不生成本地模板。原有生成执行去重及明确失败后的模板路径沿用。
- 恢复时按已知任务 ID 或原创建请求编号先查询。已有结果可在删除模型配置后直接读取，无需请求模型。原任务仍需调用时校验原服务商，原创建未到达时才允许用同一编号重发。

## 首页签到与快速打卡回执（本地）

## 管理员角色与提交权限（本地）

## 管理员删除与批量清理（本地）

- 「管理后台 → 系统工具」的批量清理保存首次确认的账号 ID，二次确认、取消和回执查询使用该批次。等待期间新注册的账号不纳入。任一现任管理员可以查看并明确确认或取消当前批次。取消恢复成员的原状态，单人入口不能拆开批量操作。完成回执与删除一同提交，重开页面可查看，开启下一批需重新确认。
- 单人删除和批量清理先核对账号及归属，读失败、重复归属和超过 50 条（含账号）均在准备或提交前停止。首次确认暂停账号，等待至少 60 秒再确认，重新扫描后在同一事务删除账号、目标、任务、宠物、成长、情绪、时间胶囊、AI 记录及配置、反馈等。任一删除失败则回滚。等待或失败后可取消清理，恢复原状态。云存储文件不属于本次清理，微信登记保留用于识别旧会话。
- 待清理账号拒绝登录和新业务请求，等待窗口覆盖项目记录中新旧业务云函数的 30 秒时限。删号后必须重新注册才能使用业务，同微信重建后的账号必须携带新账号 ID，旧会话和无法携带 ID 的旧包无法操作重建账号。原有普通账号兼容旧请求格式。[CloudBase 函数超时](https://docs.cloudbase.net/cloud-function/function-configuration/config)
- Node24 全套离线回归、客户端路由专项与后台微信模板、样式编译通过。新增覆盖同批并发确认、新注册保留、取消恢复及旧批次请求失效。旧客户端缺少批次操作参数时拒绝执行批量清理。
- 上线前需核对 `app/app-node24`、`login/login-node24` 的实际超时、版本和 `account_claims` 权限，配套更新客户端。隔离环境用管理员和一个普通测试账号验证暂停、重试、取消、二次确认、重新注册与新旧请求，复核原账号记录和其他账号记录。未执行生产删除或清理。

## 森林礼包领取与状态同步（本地）
