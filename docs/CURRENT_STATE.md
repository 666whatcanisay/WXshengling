## 项目结构

| 位置 | 作用 |
|---|---|
| `project.config.json` | 微信项目配置，源码根为 `miniprogram/`，云函数根为 `cloudfunctions/` |
| `miniprogram/app.json` | 注册 18 个页面，五个底部入口：首页、目标、宠物、AI、我的 |

| `cloudfunctions/init/index.js` | 初始化集合与成就定义 |
| `miniprogram/utils/` | 宠物物种、阶段、性格、稀有度、称号、资源配置 |

## AI 的实际边界

- `aiPlannerChat`：单模型规划对话，系统提示词称为 Planner Agent；存在前端目标上下文与对话状态。
- `aiStartGenerate` → `aiDoGenerate` → `aiPollPlan`：计划记录、模型生成、结果写回与状态查询接口。不能仅凭接口命名认为已经具备独立后台任务队列。
- 本地 `aiDoGenerate` 输出约定已增加 period_days/day_index，仍为 3～6 项具体任务；尚非整个周期每天自动重复或逐日铺满。解析失败仍有通用模板兜底。
- 本地草案新增周期、开始日、每项日期/分钟编辑；发布保存阶段/时长/日期，AI 计划不再默认创建额外同名任务。隔离调用生产页面与后端的 7 天流程已验证字段保留，云端/真机未验；发布原子性、跨会话防重复和部分失败恢复仍待下一批。
- AI 教练读取部分仪表盘数据，建议主要随机取预设文案；其中目标数为零时可回退显示为 3。
- 宠物聊天为关键词/随机回复，同时尝试调用云端互动。
- 命名、运势、人格卡、未来来信等为本地模板/规则。成长翻译当前是字符变换示例，不具备真实中英翻译能力。
- 时间胶囊有云端保存/查询路径；保存失败时仍可能显示已封存，需运行核实持久化体验。
- 当前未发现已落地的多 Agent 调度、互审修订或协作运行记录。

## 宠物与后端基础

物种配置有 15 种、森林/家园/荒野三类蛋；成长为蛋、幼体、青年、成年、完全体。四维属性为活力、智慧、幸运、共鸣，含物种概率池、稀有度、颜色、性格、亲密度与称号等配置。当前孵化初始属性必走均衡池，正常路径每种蛋只能得到 3 种，共 9 种；不能将 15 种配置理解为全部正常可获取。三档颜色目前映射同一张基础云图片。

物种 Buff 有展示但结算未接倍率；天赋加成函数存在但未进入阶段奖励。一次给蛋投入超过孵化阈值的泉水会损失超出部分；互动与外观判断使用不同成长字段。上述已在本地当前源码复现，尚未修复。

主要数据集合：`users`、`goals`、`tasks`、`pets`、`checkins`、`achievements`、`emotions`、`growth_logs`、`api_keys`、`feedbacks`、`ai_plans`、`user_growth_pool`、`capsules`、`announcements`。其他宠物事件/信件字段或集合需按实际流程进一步追踪。

后端有信件查询/已读/收集相关 action，但统一前端 API 封装未发现对应方法；暂不宣称完整用户信件闭环。
