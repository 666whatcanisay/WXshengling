## 命名规范

```
{species_id}_{stage}_{color}.png
```

| 字段 | 可选值 | 说明 |
|------|--------|------|
| species_id | 见下方物种ID列表 | 唯一标识 |
| stage | baby / youth / adult / perfect | 4个成长阶段 |
| color | **normal** / **rare** / **shiny** | 三档颜色变体 |

**总计：15物种 x 4阶段 x 3色 = 180张**

## 颜色档次说明（V7.1）

| 档次 | 概率 | 后缀 | 视觉效果 |
|------|------|------|----------|
| 普通 normal | 92% | _normal | 标准外观 |
| 稀有 rare | 6% | _rare | 边框发光(#448AFF) + 小特效 |
| 异色 shiny | 2% | _shiny | 特殊配色 + 金色边框(#FFD700) + 闪烁 + 特殊称号 |

**收集目标：图鉴 15/15 + 稀有图鉴 15/15 + 异色图鉴 15/15 = 45个收集目标**

## 图片规格建议

- **尺寸**: 400x400px（高清Retina: 800x800px）
- **格式**: PNG（透明背景）
- **风格**: 统一的Q版/像素风/宝可梦风格
- **朝向**: 正面或3/4侧面，居中
- **异色版**: 在普通版基础上增加光泽/颜色变化效果，保持轮廓一致

## 阶段视觉差异建议

| 阶段 | 大小比例 | 特征 |
|------|----------|------|
| baby | 0.6x | 圆润、大头、可爱 |
| youth | 0.8x | 开始长开、青春活力 |
| adult | 1.0x | 成熟形态、完整特征 |
| perfect | 1.1x | 发光边框/光环、终极形态感 |

## 美术规范 (V7.1 Art Specification)

### 角色比例

| 参数 | 规范值 | 容差 |
|------|--------|------|
| 头身比 | **0.28** (头部约占身高28%) | ±0.03 |
| 宽高比 | **1.10** (身高/身宽) | ±0.15 |
| 前景占比 | 见下方阶段规范 | 见下方 |

### 头身比示意 (Q版三头身)

```
┌───┐
│ ○ │ ← 头部：占身高 28% (±3%)
├───┤
│   │
│ │ │ ← 躯干+四肢：占身高 72%
│   │
└───┘
```

### 构图规范

| 参数 | 规范值 |
|------|--------|
| 角色朝向 | **正前方** (正面或3/4侧面) |
| 角色姿态 | **站立**，四肢自然垂放或微曲 |
| 角色居中 | 重心偏移 ≤ 画布 **3%** |
| 画面裁切 | **禁止裁切** 身体任何部位 |
| 脚底留白 | 画布底部 **5%** (±2%) |
| 头顶留白 | 画布顶部 **10%** (±3%) |

### 背景规范

| 参数 | 规范值 |
|------|--------|
| 生成时背景 | **纯白色 #FFFFFF** |
| 最终输出 | **透明背景 RGBA** (4通道) |
| 抠图方式 | Flood-fill 从四边 + 软阈值过渡 (230~248) |
| 禁止 | 渐变背景、场景元素、投影、描边背景 |

### 成长阶段规范 (核心)

| 阶段 | 前景占比 | 相对面积 | 特征描述 |
|------|----------|----------|----------|
| baby | **28% ~ 33%** | 1.00× (基准) | 圆润大头，短四肢，幼态 |
| youth | **30% ~ 36%** | 1.05× ~ 1.40× | 四肢增长，身形修长，青春活力 |
| adult | **33% ~ 38%** | 1.15× ~ 1.60× | 完全成熟，完整特征展现 |
| perfect | **30% ~ 36%** | 1.05× ~ 1.40× | 光环+发光边框，体型略小于adult |

> **关键规则**: 每阶段面积应比前一阶段增长 ≥5%。如果实际面积倒退，视为生成失败，应重新生成。

### 文件规格 (最终输出)

| 参数 | 主图 | 缩略图 |
|------|------|--------|
| 尺寸 | **512 × 512 px** | **128 × 128 px** |
| 格式 | PNG RGBA | PNG RGBA |
| 通道 | 4 (含Alpha) | 4 (含Alpha) |
| 文件大小 | **≤ 300 KB** | ≤ 50 KB |
| 背景 | 透明 | 透明 |

### 微信小程序资源规范

| 参数 | 规范值 |
|------|--------|
| 主图尺寸 | 512×512 (GPU纹理友好，2的幂) |
| 缩略图尺寸 | 128×128 (列表/图鉴) |
| 单张上限 | 300KB (保证加载速度) |
| 格式 | PNG RGBA (支持任意背景合成) |
| 命名规范 | `{stage}.png` / `{stage}_thumb.png` |

### 线条风格规范 (自动验收用，非Prompt内容)

| 参数 | 验收范围 |
|------|----------|
| 轮廓占比 | 前景像素中 **4% ~ 14%** 为深色轮廓 (亮度<80) |
| 色彩饱和度 | 前景平均 HSL 饱和度 **0.30 ~ 0.70** |
| 光照均匀度 | 上下亮度比 **0.85 ~ 1.15**，左右亮度比 **0.85 ~ 1.15** |

> ⚠️ 以上线条/光照参数仅用于 `quality-gate.json` 自动验收，**不应写入 AI Prompt**（模型无法精确执行像素级指令）。

## 质量门 (Quality Gate)

自动化验收配置文件：`pipeline/quality-gate.json`

Pipeline 在 Step 3 (select_best) 阶段自动执行以下检查：

```
生成 → 计算 foreground_ratio → 对比质量门 → 不合格 → 重新生成 (最多2次)
```

### 验收规则

| 检查项 | 规则 | 不合格动作 |
|--------|------|------------|
| foreground_ratio | 阶段范围内 | 重新生成该阶段 |
| growth_area_ratio | 比前一阶段 ≥5% | 重新生成该阶段 |
| head_body_ratio | 0.22 ~ 0.34 | 警告，不阻断 |
| aspect_ratio | 0.85 ~ 1.40 | 警告，不阻断 |
| outline_ratio | 0.04 ~ 0.14 | 警告，不阻断 |
| file_size_kb | ≤300 (主图) / ≤50 (缩略图) | 提高压缩率 |
| image_size | 512×512 / 128×128 | 重新缩放 |

### 当前最大风险 🔴

**成长面积倒退**: shiba perfect 实际面积仅为 baby 的 63%，fox 全程倒退。这是产品核心体验——"成长感"——的直接威胁。Pipeline 必须通过 `growth_area_ratio` 门禁阻止此类输出。
